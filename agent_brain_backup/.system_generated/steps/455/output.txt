The search for "windows 10 remove shut down keep restart start menu registry group policy" returned the following summary:
To manage power options in the Windows 10 Start menu, you can use the Group Policy Editor or the Registry Editor. Please note that these methods generally remove the entire Power menu (including Shutdown, Restart, Sleep, and Hibernate) rather than just the Shutdown option alone.

### Important Considerations
*   **Permissions:** These changes generally affect all users on the machine.
*   **Workarounds:** Even if these options are hidden, users with sufficient privileges can still perform these actions via the Command Prompt (e.g., `shutdown /s` or `shutdown /r`) or by logging off and using the power options on the lock screen (unless further restricted).
*   **Windows Editions:** The Group Policy Editor (`gpedit.msc`) is typically available only in Pro, Enterprise, and Education editions of Windows 10.

---

### Method 1: Using Local Group Policy Editor (Recommended)
This is the standard way to restrict power commands:

1.  Press `Win + R`, type **`gpedit.msc`**, and press **Enter**.
2.  Navigate to: **User Configuration** > **Administrative Templates** > **Start Menu and Taskbar**.
3.  In the right pane, locate the policy named: **"Remove and prevent access to the Shut Down, Restart, Sleep, and Hibernate commands"**.
4.  Double-click it and select **Enabled**.
5.  Click **Apply** and **OK**.
6.  To apply the change immediately, you can run `gpupdate /force` in a Command Prompt, or simply restart your system.

---

### Method 2: Using Registry Editor
If you are using Windows 10 Home or prefer to use the Registry, you can create the `NoClose` value:

1.  Press `Win + R`, type **`regedit`**, and press **Enter**.
2.  Navigate to: `HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\Explorer`
    *   *Note: If the `Explorer` key does not exist under `Policies`, right-click `Policies`, select **New > Key**, and name it `Explorer`.*
3.  In the right pane, right-click an empty area and select **New > DWORD (32-bit) Value**.
4.  Name the new value **`NoClose`**.
5.  Double-click **`NoClose`** and set its "Value data" to **`1`**.
6.  Close the Registry Editor and restart your computer for the changes to take effect.

---

### Is there a way to keep "Restart" but remove "Shut Down"?
There is no built-in native Windows setting to hide only the "Shut Down" button while keeping "Restart" visible in the Start menu. 

Some users attempt to use `HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\PolicyManager\default\Start\HideShutDown` by setting the value to `1`. While this may hide the shutdown option in certain contexts, it is not a fully supported policy for granular control and may not behave consistently across all Windows 10 versions or user environments. For professional environments, administrators often use custom scripts or shortcuts (e.g., pinning a custom "Restart" batch file to the Start menu) to provide users with the specific functionality they need while restricting others.
