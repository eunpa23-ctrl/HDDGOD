The search for ""HideShutDown" windows 10 start menu PolicyManager" returned the following summary:
The registry path `HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\PolicyManager\default\Start\HideShutDown` is a known method used to hide the "Shut Down" option from the Windows 10 Start Menu power options[1][2][3].

### How to use it
By modifying the `value` data at this location, you can remove the Shut Down command while leaving other options (like Restart or Sleep) visible[1][4][5]:

1.  Press `Win + R`, type **regedit**, and press **Enter**.
2.  Navigate to: `Computer\HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\PolicyManager\default\Start\HideShutDown`[1][3].
3.  Double-click the **value** item in the right pane[1][4].
4.  Change the **Value data** from `0` to `1`[1][4][5].
5.  Click **OK**. Changing the value back to `0` will restore the option[1][4].

### Important Considerations
*   **System-Wide Effect:** Because this registry key is located in the `HKEY_LOCAL_MACHINE` hive, it applies system-wide to all users[2][6]. There is no native Windows method to scope this specific registry change to only a specific user group[2].
*   **Does Not Prevent Shutdowns:** This method only removes the "Shut Down" option from the UI (Start Menu, sign-in screen, etc.)[1][4][3]. It does **not** prevent a user from shutting down the computer using other methods, such as the Command Prompt (`shutdown /s /t 0`) or other applications[1][2][3].
*   **Group Policy Alternative:** The standard Group Policy setting "Remove and prevent access to the Shut Down, Restart, Sleep, and Hibernate commands" (located in *User Configuration > Administrative Templates > Start Menu and Taskbar*) is often used to manage power options, but it typically removes **all** power commands rather than just the Shut Down button[2][3][7]. If you need to keep "Restart" available, the registry method above is the most common workaround[2][8].
