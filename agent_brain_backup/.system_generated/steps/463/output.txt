To hide the "Shut down" option from the Start menu using the registry, you can modify the `HideShutDown` policy key[1][2].

### Registry Method
1.  **Open Registry Editor**: Press `Win + R`, type `regedit`, and press **Enter** (ensure you have administrator privileges)[2][3].
2.  **Navigate to the Key**: Go to the following path[4][2]:
    `HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\PolicyManager\default\Start\HideShutDown`
3.  **Modify the Value**:
    *   Find the DWORD value named `value` in the right pane[1][5].
    *   Double-click it and change the **Value data** to `1` to hide the option[1][2].
    *   (To revert this later, change the value back to `0`)[1][2].

### Command Line Method
You can also perform this action by running the following command in an elevated Command Prompt or PowerShell terminal[4][3]:

```cmd
reg add "HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\PolicyManager\default\Start\HideShutDown" /v value /t REG_DWORD /d 1 /f
```

### Important Considerations
*   **System-Wide Impact**: This setting is located under `HKEY_LOCAL_MACHINE`, meaning it applies system-wide to all users and cannot be easily scoped to specific users only[6][7].
*   **Not a Security Feature**: This method only removes the "Shut down" option from the visual UI (Start menu, sign-in screen, etc.)[1][3]. It does not prevent a user with sufficient privileges from shutting down the computer via other methods, such as the command line (`shutdown /s /t 0`), `Alt+F4`, or `Ctrl+Alt+Del`[6][2][3].
*   **Backup**: It is always recommended to back up your registry before making changes[3][8].
