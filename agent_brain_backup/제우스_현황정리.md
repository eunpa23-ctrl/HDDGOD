## 🔄 OTP 자동화 흐름 (구현 완료, 테스트 대기 중)

```
손님이 넷플릭스 아이콘 클릭
    ↓
에이전트: 이메일(eunpa23@naver.com) 자동 입력
    ↓ (2단계)
에이전트: 다음 버튼 클릭 → 비밀번호(@Oep0325) 자동 입력 → 로그인
    ↓ (OTP 화면 뜨는 경우)
에이전트 → 서버에 OTP_REQUIRED 신호 전송
    ↓
서버: 네이버 IMAP 접속 (최대 35초간 2초마다 메일 감시)
    ↓
넷플릭스 발신 메일에서 4자리 코드 자동 추출
    ↓
서버 → 에이전트에게 코드 전송
    ↓
에이전트: 손님 PC 화면에 4자리 코드 자동 타이핑 → 로그인 완료 🎉
    ↓ (35초 초과 시 fallback)
카카오 알림톡 + 수동 OTP 입력 페이지 제공
```

## ⏳ 테스트 필요한 항목 (우선순위 순)

> [!IMPORTANT]
> 아래 항목들은 코드 수정은 완료되었으나 아직 실제 손님 PC에서 검증이 안 된 상태입니다.

| 우선순위 | 테스트 항목 | 방법 |
|---------|-----------|------|
| 🔴 1순위 | **원격 업데이트(OTA)** - 대시보드 "전체 에이전트 업데이트" 후 v1.0.8 전환 확인 | 대시보드 → 전체 업데이트 버튼 → 손님 PC 트레이 버전 확인 |
| 🔴 1순위 | **넷플릭스 2단계 자동 로그인** - 아이디/비밀번호 자동 입력 및 로그인 완료 여부 | 손님 PC 바탕화면 넷플릭스 아이콘 클릭 |
| 🟡 2순위 | **OTP 4자리 자동 추출** - 넷플릭스가 OTP 요청 시 메일에서 자동 추출 및 입력 | 넷플릭스 로그인 후 OTP 창 뜰 때 자동 처리 확인 |
| 🟢 3순위 | **에러 텔레메트리** - 클라이언트 비정상 종료 후 재접속 시 서버에 crash.log 전달 | `server/error_reports.log` 파일 생성 확인 |

## 📁 프로젝트 폴더 구조

```
HDDGOD/
├── client/                  # 손님 PC 에이전트
│   ├── client_agent.py      # 메인 루프 (서버 통신, 텔레메트리)
│   ├── client_tray.py       # 트레이 아이콘 UI (버전 표시 포함)
│   ├── netflix_bot.py       # 넷플릭스 자동 로그인 봇 ← v1.0.8 핵심 수정
│   └── uwf_controller.py    # 순간복구 제어
├── server/                  # 카운터 PC 관제 서버
│   ├── server_core.py       # WebSocket 서버 (에러 리포트 수신기 포함)
│   ├── mail_otp_extractor.py# 네이버 메일 OTP 자동 추출기
│   └── templates/           # 대시보드 웹 UI
├── common/
│   ├── config.py            # 공통 설정 (계정정보 fallback 포함)
│   └── protocol.py          # 통신 규격 (ERROR_REPORT 추가)
├── deploy/ClientDeploy/
│   ├── 1_설치하기.bat        # 원클릭 설치 스크립트 (CP949 인코딩 고정)
│   └── core/                # ZeusAgent.exe + version.txt
├── .gitignore               # Git 제외 목록
└── ZeusAgent.spec           # PyInstaller 빌드 설정 (백신 오진 방지 경로 설정)
```
