2. 프로젝트 주요 내용 (HDDGOD)
------------------------------------------------------------------------
본 프로젝트는 다수의 클라이언트 PC를 중앙에서 관제하고 보호하기 위한 '제우스 HDD PROTECTOR' 시스템입니다.
- 주요 기능:
  * UWF (Unified Write Filter) 기반의 디스크 보호 및 1초 순간 복구 모드 제어
  * 클라이언트 무인 자동 업데이트 (OTA 기능)
  * PicaLive (피카라이브) 무인 감시 및 자동 로그인 (Watchdog)
  * 넷플릭스 자동 로그인 봇 기능
  * 전원 관리 정책 (WOL 자동 부팅, 유휴 시 절전 등)
  * 텔레그램 연동 실시간 상태 알림 및 로그 모니터링

3. 주요 대화 및 문제 해결 목록 (최근 히스토리)
------------------------------------------------------------------------
- [기능 추가] 클라이언트 OTA 업데이트 시각화: 다운로드 프로그레스 바(%) UI 및 업데이트 완료 팝업(UWF 상태 표시 포함) 추가.
- [버그 해결 1] Windows Defender 바이러스 오진 및 삭제 문제: PyInstaller 단일 파일 빌드 시 vcruntime140.dll 파일을 내장(Add-Binary)하여 DLL 로드 에러 원천 차단.
- [버그 해결 2] pyi_application_home_dir 환경변수 에러: 구버전 에이전트가 새 버전을 실행할 때 PyInstaller 환경변수가 상속되어 뻗는 고질적 버그를 clean_env (환경변수 초기화) 적용으로 완벽히 해결.
- [버그 해결 3] 네트워크 공유 폴더(UNC) 실행 오류: CMD가 UNC 경로를 지원하지 않아 update.bat가 실패하는 문제를, 가상 드라이브(pushd) 대신 절대 경로(%~dp0)를 사용하도록 전면 수정하여 원격 폴더 직접 실행 환경에서도 완벽히 업데이트되도록 개선.
- [버그 해결 4] 파이썬 스코프(Scope) 에러: 함수 내부에서 중복 import os 사용으로 인해 발생한 UnboundLocalError 즉각 패치.
