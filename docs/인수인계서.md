# ⚡ 제우스 HDD PROTECTOR - 통합 인수인계 및 개발 요약서
**최종 업데이트:** 2026년 10월 1일

## 1. 시스템 아키텍처 및 개요
이 프로젝트는 PC방 클라이언트 PC를 중앙 카운터에서 완벽하게 통제하고 모니터링하기 위한 통합 관제 솔루션입니다.
- **서버 (카운터 PC):** FastAPI 기반 웹 서버. 로컬 대시보드 및 Cloudflare 터널을 통한 모바일 외부 원격 제어 제공.
- **클라이언트 (손님 PC):** `ZeusAgent.exe` (파이썬 코드를 PyInstaller로 빌드한 단일 실행 파일). 윈도우 시작 시 자동 실행되며 서버와 웹소켓으로 실시간 통신.
- **이중 저장소 동기화 원칙 (중요):**
  - 원본 A: `G:\내 드라이브\PROJECT\HDDGOD` (구글 드라이브 클라우드 동기화)
  - 원본 B: `C:\Users\USER\Documents\HDDGOD` (C드라이브 내문서 로컬 미러)
  - 모든 코드 수정/추가/삭제 작업은 **반드시 두 저장소에 동시에 1:1 반영**되어 항상 동일한 상태를 유지합니다.

## 2. 방금 전까지 완료된 최신 작업 내역 (매우 중요)
다른 PC에서 이어서 작업할 때 다음 내역이 현재 시스템에 모두 적용되어 있음을 인지해야 합니다.

1. **실행 창(검은 CMD 창) 완전 숨김 처리**
   - 기존의 `.bat` 실행 파일들을 삭제하고, `서버실행.vbs`, `클라이언트실행.vbs`로 교체하여 백그라운드에서 창 없이 완벽하게 실행되도록 변경했습니다.
2. **텔레그램 알림 기능 안정화**
   - 서버 구동 시 Cloudflare 터널이 열리면 텔레그램으로 외부 접속 모바일 대시보드 URL을 정상적으로 발송합니다. (lifespan 기반 동작)
3. **클라이언트 자동 업데이트 (OTA) 기능 탑재**
   - 대시보드에서 `[전체 에이전트 업데이트]` 버튼을 누르면 클라이언트가 서버(`deploy/ClientDeploy/core/ZeusAgent.exe`)에서 최신 파일을 몰래 다운로드하고, 자신을 강제 종료한 뒤 덮어쓰고 스스로 재시작합니다.
   - 윈도우 UWF(순간복구)가 켜져 있어도 `C:\ZeusAgent` 폴더가 예외 처리되어 있어 업데이트가 영구 보존됩니다.
   - 현재 클라이언트 버전: `1.0.1` (`deploy/ClientDeploy/core/version.txt` 참조)
4. **모바일 원격 제어 화면 고도화**
   - **해상도 상향:** `screen_streamer.py`의 캡처 해상도를 960에서 `1920x1080` (퀄리티 75)으로 상향했습니다.
   - **조작 기능:** 모바일 터치 시 발생하는 브라우저 스크롤 현상을 차단하고, **두 손가락 확대/축소 (Pinch-to-zoom)** 및 **한 손가락 이동(Pan)** 기능을 바닐라 JS로 완벽히 구현했습니다.
   - 확대된 상태에서도 좌표 매핑이 완벽하게 이루어져 탭(클릭)한 위치의 PC 마우스가 정확히 눌립니다.
5. **대시보드 환경설정 톱니바퀴 모달 및 통합 관리 API 탑재**
   - 대시보드 우측 상단에 `[⚙️ 환경설정]` 버튼을 신설하여 모달 팝업으로 전체 설정을 제어할 수 있습니다.
   - **서버 IP 설정**: `SERVER_HOST`, `SERVER_PORT`, `CLIENT_SERVER_IP`, 관리자 비밀번호를 UI에서 바로 수정 및 영구 저장(`config.ini`).
   - **클라이언트 업데이트 제어**: 현재 버전 확인/수정 및 전체 클라이언트에 OTA 강제 업데이트 명령 원클릭 발송.
   - **텔레그램 알림**: 봇 토큰 및 Chat ID 실시간 수정 및 테스트 발송.
6. **서버 비정상 종료 시 무한 자동 재시작 감시자 (Supervisor) 구현**
   - [server_supervisor.py](file:///G:/내%20드라이브/PROJECT/HDDGOD/server_supervisor.py) 신설: 서버 프로세스가 비정상 종료되거나 예외 크래시 발생 시 2초 내에 즉시 백그라운드에서 자동 부활.
   - [서버실행.vbs](file:///G:/내%20드라이브/PROJECT/HDDGOD/서버실행.vbs)가 감시자를 무음 실행하여 24시간 무중단 가동 보장.
7. **윈도우 시작 시 서버 자동 실행 (Startup Auto-run) 기능 완비**
   - 레지스트리(`HKCU\Software\Microsoft\Windows\CurrentVersion\Run -> ZeusServer`) 제어 API(`/api/settings/autostart`) 탑재.
   - 대시보드 환경설정 모달에서 [등록] / [해제] 버튼으로 실시간 켜기/끄기 지원.
   - 원클릭 배치 파일([관리도구_서버_윈도우시작_등록.bat](file:///G:/내%20드라이브/PROJECT/HDDGOD/관리도구_서버_윈도우시작_등록.bat), [관리도구_서버_윈도우시작_해제.bat](file:///G:/내%20드라이브/PROJECT/HDDGOD/관리도구_서버_윈도우시작_해제.bat)) 동시 제공.
8. **배포 경로 참조 버그 픽스**
   - [server_core.py](file:///G:/내%20드라이브/PROJECT/HDDGOD/server/server_core.py) 내 `version.txt` 및 `ZeusAgent.exe` 경로가 `server/deploy/`를 잘못 가리키던 문제를 프로젝트 루트 경로(`PROJECT_ROOT/deploy/`)로 정밀 수정.
9. **모바일 대시보드 환경설정 연동 및 감시자(Watchdog) 실시간 동기화 완비**
   - [mobile_dashboard.html](file:///G:/내%20드라이브/PROJECT/HDDGOD/server/templates/mobile_dashboard.html) 헤더에 톱니바퀴 버튼(`⚙️`) 및 모바일 전용 환경설정 모달 탑재 (스마트폰에서도 부팅 시 자동실행 토글, 원격 OTA 무인 업데이트, 카운터 IP/비밀번호 변경 가능).
   - [server_supervisor.py](file:///G:/내%20드라이브/PROJECT/HDDGOD/server_supervisor.py) 감시자 루프를 논블로킹 폴링 방식으로 고도화하여 실시간 하트비트 갱신 보장 (`supervisor_active: True`).
   - `version.txt`의 UTF-8 BOM 인코딩을 정밀 교정하여 버전 비교 및 OTA 업데이트 안정성 극대화.
10. **클라이언트 배포 배치파일(`1_설치하기.bat`, `2_정밀검수.bat`) 안정화**
    - 네트워크 공유 UNC 경로(`\\192.168.0.100\...`)에서 실행 시 CMD가 `System32`로 튕기던 현상을 `pushd "%~dp0"` 가상 드라이브 마운트로 해결.
    - 윈도우 한글 CMD 파서와 충돌하던 UTF-8 이모지(`⚡`, `🎉`) 제거 및 순수 **CP949 + CRLF** 인코딩으로 완전 재변환하여 명령어 문법 깨짐 오류 완벽 방지.

## 3. 프로그램 실행 방법
- **서버 구동:** `G:\내 드라이브\PROJECT\HDDGOD\서버실행.vbs` 더블클릭
- **클라이언트 구동:** `클라이언트실행.vbs` 더블클릭 (개발/테스트 용도)

## 4. 실제 매장(클라이언트 PC) 배포 방법
1. **서버 세팅:** 카운터 PC에서 `deploy\share_deploy_folder.bat`을 관리자 권한으로 실행해 폴더를 네트워크에 공유.
2. **클라이언트 세팅:** 손님 PC에서 공유 폴더(`\\카운터IP\ClientDeploy`)로 접속 후, `1_설치하기.bat`을 **관리자 권한**으로 실행.
3. 10초 후 설치 완료 및 UWF(순간복구) 세팅이 끝나면 PC 재부팅.

## 5. 향후 유지보수(코드 수정) 시 가이드
만약 클라이언트 쪽 코드(`client_agent.py`, `screen_streamer.py` 등)를 수정했다면 반드시 다음 단계를 거쳐야 합니다.
1. `deploy\build_client_exe.bat` 실행 (새로운 `ZeusAgent.exe`가 빌드되어 배포 폴더로 복사됨)
2. `deploy\ClientDeploy\core\version.txt` 안의 숫자 변경 (예: 1.0.1 -> 1.0.2)
3. 대시보드(PC/모바일)에서 `[전체 에이전트 업데이트]` 버튼 클릭 -> 전체 PC 자동 패치 완료!
